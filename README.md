# Birds N Boats

Fly as a bird or drive a boat across an endless world of hills and lakes, and catch fish. Press **B** at any time to teleport between a random bird or boat that you can control. You can zoom out and look around for fun.

[Watch the game demo](https://youtu.be/ttGcYPGcqrM)

Terry classified Talons as unfun so I went on a quest to make it fun! Sick of crashing your bird into hills? Now it's avoidable, quick transfer to a boat before you crash! Bird hard to turn? It's easier in 3rd person view, line yourself up and switch to 1st person for the final catch with classic Talons controls! Sick of flying off the edge of the world and needing to slowly turn around? The world is endless now! Ever say to yourself I wish I could drive that boat on the lake down there? Now you can!

## Objective

Catch 10 fish as a bird and 20 fish as a boat. **Fish Remaining** shows the count for whichever you are right now. The game is won when both counts reach zero, and your fastest time is saved as **Best**.

## Bird Controls

| Key | Action |
| --- | --- |
| Up / Down | Nose down (dive) / nose up (climb) |
| Left / Right | Roll to turn |

Swoop down to catch fish from the water.

## Boat Controls

| Key | Action |
| --- | --- |
| Up / Down | Throttle up / down (down past zero reverses) |
| Left / Right | Turn |
| Space | Stop |

Drive over fish to catch them (you just run them over, that's what you do!).

## Camera Controls

| Key | Action |
| --- | --- |
| + / - | Zoom in / out (1st vs 3rd person view) |
| [ / ] (, / .) | Rotate the camera left / right |
| ; / ' (PgDn / PgUp) | Lower / raise the camera |
| R | Reset camera zoom/angles to default |

The camera keys work for the boat and for the bird when zoomed out.

## Other Keys

| Key | Action |
| --- | --- |
| B | Switch between bird and boat |
| Enter | New Map |
| ESC | Quit |
| Shift-ESC | Abort |

## Tips

- About to crash as a bird? Press **B** to become a boat before you crash!
- Catch fish in 1st person view (zoomed in), 3rd person is mainly for fun.
